## How updates work

The default workflow is **one completed anime review and tier placement per commit**. This keeps each addition focused and gives the repository history a readable viewing journal.

1. Copy [`reviews/_template.md`](reviews/_template.md) to `reviews/<anime-slug>.md`.
2. Replace every placeholder with my own notes and rating.
3. Add the review link to one tier above.
4. Commit the review and tier placement together.

See [CONTRIBUTING.md](CONTRIBUTING.md) for naming, commit, and optional progress-note conventions.

## Review format

Reviews record the title, viewing status, episodes watched, completion date, spoiler-free summary, highlights, drawbacks, final thoughts, score, and tier. The template does not prescribe ratings or invent viewing history.
